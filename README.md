# Data Science Portfolio

Welcome to my Data Science portfolio. This repository showcases a collection of end-to-end data science projects, focusing on machine learning, statistical analysis, and production-grade ML systems.

## Projects

### 1. [Large-Scale Recommendation System](./1_recommendation_system)
A Netflix-style recommendation engine using the MovieLens dataset, implementing collaborative filtering, matrix factorization, and neural recommenders.

### 2. [End-to-End Fraud Detection](./2_fraud_detection_ml)
A robust fraud detection system designed for fintech applications, featuring advanced feature engineering and imbalanced learning techniques.

### 3. [A/B Testing & Experimentation Platform](./3_ab_testing_engine)
A comprehensive platform for product experimentation, implementing statistical hypothesis testing and Bayesian analysis.

### 4. [NLP Sentiment & Review Analytics](./4_nlp_review_analysis)
A large-scale NLP pipeline for analyzing customer sentiment and extracting topics from millions of reviews using BERT.

### 5. [Time Series Sales Forecasting](./5_time_series_forecasting)
A demand forecasting system using ARIMA, Prophet, and LSTM to predict retail sales trends.

### 6. [Data Pipeline & MLOps](./6_ml_pipeline_mlops)
A production-grade ML pipeline demonstrating experiment tracking with MLflow and automated workflows.

### 7. [RAG Retrieval & Evaluation](./7_rag_retrieval_evaluation)
Advanced RAG system focusing on retrieval metrics, reranking, and enterprise-scale knowledge access.

### 8. [Customer Churn Prediction](./8_customer_churn_prediction)
Subscription churn modeling with LightGBM, SMOTE option, SHAP-friendly workflow, and a Streamlit demo dashboard.
